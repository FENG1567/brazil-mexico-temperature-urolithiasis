# Code availability

The v1.1.1 reproducibility release (corrected-results identity TEMP-20261115-C1) is prepared for https://github.com/FENG1567/brazil-mexico-temperature-urolithiasis. It includes the compact corrected Brazil geographic-day temperature panel and its fixed-grid weight table, plus code and instructions for rebuilding the five main figures and three main tables from packaged aggregate results. The default figure/table build does not fit models or recreate upstream raw weather inputs. The historical v1.0.0 release remains available unchanged.
