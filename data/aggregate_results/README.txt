Supplementary aggregate data

This archive contains aggregate descriptive counts, model estimates, covariance
objects and diagnostics, sample-flow checks, public method-source records, and
sensitivity analyses supporting the manuscript. The files contain no
patient-level records or individual admission or procedure identifiers.

Content is grouped by scientific topic: descriptive results, main tables,
covariance diagnostics, temperature-spline results, Brazilian service models,
alternative model results, and sensitivity results. Supplementary Methods and
Tables define the study populations, units, exposure windows, model
specifications, and interpretation of each analysis.

Results from alternative model specifications are labeled separately. Use the
corresponding manuscript and supplementary definitions when interpreting them.
