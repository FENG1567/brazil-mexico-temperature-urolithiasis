# Rebuilding the released figures and tables

Code release: v1.1.0. Corrected-results identity: TEMP-20261115-C1. The historical v1.0.0 package remains unchanged.

## Supported scope

The package-level command checks manifest-listed payloads, then rebuilds five figures and three main tables from the corrected aggregate and figure-input files packaged with v1.1.0. It does not download source data, regenerate analytical panels, recalculate effect estimates, or fit models. The corrected Brazil panel is a separate input for explicitly requested service/nonlinear model reruns; it is not read by the aggregate figure/table builder. See [Temperature-input correction](temperature_input_correction.md) for input scope, checksums, and prerequisites.

## Environment and commands

The tested plotting environment used Python 3.12.3, Matplotlib 3.11.2, NumPy 2.5.4, pandas 3.1.1, SciPy 1.18.1, and python-docx 1.2.0. The package build's direct dependencies are pinned in `requirements-figures.txt`; transitive packages are resolved by pip and are not locked here.

From the repository root, with Python 3.12 active:

```sh
python -m pip install -r requirements-figures.txt
python reproduce.py --verify-only
python reproduce.py
```

The `--verify-only` command verifies manifest-listed payload files. The checker requires the columns `path`, `sha256`, `bytes`, and `role`, and validates repository-relative paths, file sizes, and SHA-256 hashes. Rows classified as generated by their role or path are skipped. `--verify-only` stops after this check. The default command then runs both builders.

## Outputs

- `artifacts/figures/fig1` through `fig5` as PDF, PNG, and TIFF.
- Editable SVG figure sources in `artifacts/figures/svg/`.
- `artifacts/provenance/figure_sources.json`, which records figure input files, hashes, selected rows/values, and output hashes.
- `artifacts/tables/table1.csv` through `table3.csv`, copied from the released main-table CSVs, plus editable `table1.docx` through `table3.docx`.

The `artifacts/` directory is ignored by Git. Reference PDFs under `reference/figures/`, if present, are optional and are not read by either builder.

## Input groups

The build consumes `data/figure_inputs/`, the supplementary aggregate results under `data/aggregate_results/`, and `data/aggregate_results/main_tables/table1.csv` through `table3.csv`. The figure builder uses source-mapped frozen, upgrade, and revision aggregate inputs. The corrected panel at `data/processed_inputs/panel_composite_humidity_exposure_repaired.parquet` is outside this aggregate build.


## Figure typography

The figure layout uses uppercase 18-point Arial Bold panel labels and bold text throughout. The five figures render the observations, estimates, intervals, and annotations stored in the v1.1.0 aggregate inputs; this build does not refit models. To reproduce the Arial rendering on a machine where Arial is not installed, set `FIGURE_FONT_DIR` to a local directory containing legitimately available Arial TrueType fonts before running the build. Font files are not distributed in this repository. Matplotlib otherwise searches the installed sans-serif fallback list, so font substitution may change line breaks and spacing. PDF/SVG retain editable text, PNG is 300 dpi, and TIFF is 600 dpi with LZW compression. This display revision does not refit any models.


## Figure reader revision

The historical v1.0.0 package retains the Display-3 figure-caption revision. The v1.1.0 figures use the corrected aggregate inputs packaged with this release. Rebuild them from the repository root with `python reproduce.py`; the font setup note above describes the local Arial requirement. No font files are included in the release.
